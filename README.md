
# Serviço de Notificação

Microsserviço backend desenvolvido com **Java** e **Spring Boot** responsável pelo tratamento de notificações dentro da arquitetura de microsserviços do sistema.

Este serviço foi criado para simular uma separação mais realista de responsabilidades, isolando o fluxo de notificações em um módulo independente.

Este serviço atua como componente complementar da solução em microsserviços, responsável pelo domínio de notificações e pelo desacoplamento dessa responsabilidade da lógica principal de usuários e tarefas.

---

## Objetivo do serviço

Este microsserviço foi desenvolvido com foco em:

- separação de responsabilidades em arquitetura distribuída
- tratamento de notificações em serviço independente
- organização de fluxo entre serviços
- construção de backend modular com Spring Boot

---

## Responsabilidades

- receber eventos ou solicitações relacionadas a notificações
- processar o fluxo de notificação do sistema
- atuar como serviço complementar dentro da arquitetura
- desacoplar notificações da lógica principal da aplicação

---

## Tecnologias utilizadas

- **Java**
- **Spring Boot**
- **Docker**

---

## Conceitos aplicados

- arquitetura de microsserviços
- separação de responsabilidades
